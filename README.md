"Gaslighting" — one word for your Wi-Fi: full bars, "Connected", nothing loads, and the router insists everything is fine. The program writes it to `/output/entry.txt` — exactly 1 word, 11 characters (gate: 1–20 characters).

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt`.
